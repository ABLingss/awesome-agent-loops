三个可复用 Loop 模板

PR babysitting

/loop 20m 检查 PR 1234 的 CI 和 PR 评论；只修复已授权的问题；合并或关闭后停止 state.json {"last_sha":"a4c9e12","ci":"pending","round":3,"budget":7} actions: checkout → inspect → patch → test → report verify: git diff --check && npm test && gh pr checks 1234 stop: merged | closed | round == 10 | budget == 0

Research watch

/loop 1h 检查 sources.md 中的来源；只追加 2026-11-05 之后的新证据；更新 evidence.md state.json {"last_seen":"2026-11-05T13:40+08:00","new_items":2,"sources":12} actions: fetch → compare → cite → deduplicate → append verify: 链接可访问 + 记录标题、日期、URL + 去重 stop: 2026-11-05T18:00+08:00 | no_new_items | budget == 5

Bug fix

/loop 10m 运行 tests/login.test.ts；定位根因；修复一个问题；重新验证 state.json {"test":"tests/login.test.ts","round":2,"failures":1} actions: reproduce → localize → patch → test → review verify: npm test -- tests/login.test.ts && git diff --check && git diff --stat stop: all_green | round == 8 | needs_human_review

预设关键词：status 看状态；resume 恢复；stop 停止；/context 看上下文；/review-pr 调用 Skill；Codex 对应使用 /goal status / /goal stop。

find-skills

code-review

senior-devops

systematic-debugging
用 observe → hypothesis → test → verify 替代盲目重试。
