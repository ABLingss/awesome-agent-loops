一个可以直接讲的 Loop3 / 5 · 2 min

PR babysitting：每轮都可验证

$ /loop 20m check CI and review comments; fix only authorized failures; stop when merged or closed state.json { "last_sha": "abc123", "last_ci": "pending", "round": 3, "budget_left": 7 } verify: git diff --check verify: npm test stop: merged | closed | budget == 0

这段话里已经有 5 个设计点

Interval：20 分钟，不在运行中的 turn 中插入。

Idempotency：用 `last_sha` 避免重复处理同一个状态。

State：把轮数、CI 状态和预算写出来。

Verification：每次修改后跑检查。

Stop：合并、关闭、预算耗尽都停止。

Loop 负责“再来一轮”，Skill 负责“这一轮怎么做”。
